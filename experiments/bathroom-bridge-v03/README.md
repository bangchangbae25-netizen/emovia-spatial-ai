# EMOVIA 욕실 도면 → 공간 구조 → 연구용 Lock → 스타일 → 검증 | v0.3.1

## 사용자 실행

- **가장 편리함**: 별도 `EMOVIA_욕실_도면인식_구조잠금_통합테스트_V03.html` 한 파일을 열면 원본 참조 아파트 이미지까지 내장되어 작동합니다.
- **ZIP**: 압축 해제 후 `index.html`을 엽니다. 상대경로 `app/` 및 `source/`를 유지해야 합니다.
- **기본 선택**: `REFERENCE_1000026121_USER_ARCHIVE`의 `R1000026121_BATH_LEFT` (실제 LH66D 아님). 오른쪽 욕실은 다른 형상(7꼭짓점)입니다.
- **LH 66D**: 면적 메타데이터만 있어 구조 좌표를 제공하지 않으며 이미지 생성 승인은 BLOCK으로 유지합니다.
- 고객 도면 업로드(PNG/JPG/WebP, 25MB 이하) → 경계점과 설비 후보 표시 → 연구용 후보 지문 → 세 가지 스타일 도형 비교 → 이미지 수동 QA → JSON 내보내기.
- 모든 업로드는 현재 브라우저의 로컬 메모리에서만 처리하며, 서버 업로드나 저장 API는 없습니다.

## 실제 구현 범위

1. 도면 원본/업로드 이미지 표시, 욕실별 독립 ID, 픽셀 좌표에 따른 경계선·설비 마커 표시.
2. 경계점 추가/이동/undo/reset, 문·세면기·양변기·배수구 후보 표시. **자동 도면인식 기능은 구현되지 않음**.
3. 연구용 baseline 스냅샷 및 SHA-256(사용 가능 브라우저) 또는 FNV32(대체 지문). **Master 공식 Geometry Lock이 아님**.
4. 구조와 디자인 Overlay를 분리. 구조 변경·샤워부스/벽체/니치 지시·승인 사칭·다른 욕실 혼입·좌표 오염 방어.
5. 구조 후보를 공유하는 모던/내추럴/클래식 비실측 2.5D 도형 비교. **고객용 실사 사진이 아님**.
6. 외부 생성 이미지를 가져와 벽/개구부/설비/시점/비변경 영역 5항목을 수동 점검. FAIL 또는 REVIEW만 나오며 자동 PASS와 자동 배포 없음.
7. 후보 JSON 내보내기. 공식 승인·실측·R01/R02 수신 ACK·카메라·Same Bathroom은 모두 미확보로 명시.
