# EMOVIA MATERIAL101 V3 — 4배색 공동 재질 배치 및 공간 영역 후보 인식

상태: 개발 실증용. 실제 시공·제조사 제품 색상·현장 안전 인증 승인 전.

## 구현
- COLOR101 101개 팔레트, 팔레트당 4색, 총 404개 슬롯 보존.
- 거실·침실·사무실·상업공간·주방·욕실 / 바닥 마루·카펫·타일 / 3가지 마감 방향 / 7개 조명 조건의 시각화.
- 사진 업로드 및 사람이 지정하는 다각형 영역 편집.
- 사용자가 AI 영역 분석을 눌렀을 때 Transformers.js + SegFormer ADE20K 모델로 벽, 바닥, 가구/수납, 패브릭 후보를 인식하도록 연결.
- AI 후보를 자동 확정하지 않고 사용자 승인, 색상 슬롯 지정, 마스크 지우개 및 수동 영역 보정 지원.
- 공간 유형이나 재질을 바꾸면 기존 후보 중 부적합한 적용을 자동 해제.
- 4색 동시 배치, 고채도·저명도 면적, 영역 중첩, Zone 적합성, 제품 검증 상태 표시.
- 사진 합성 A/B 이미지 브라우저 내 임시 저장.

## 규칙 검증
101 팔레트 × 6 공간 × 3 바닥 설정 × 3 마감 = 5,454 조합에서 기본 Zone 금지 규칙 위반 0건. 원본 카탈로그 404개 HEX 값과 V3 데이터 일치 확인. 테스트용 가상 분할 마스크로 후보 생성, 수동 보정, 배치, A/B 저장과 욕실 바닥 부적합 자동 해제를 검증.

## 검증 범위의 한계
AI 모델의 실제 사진 추론은 작업 환경의 외부 네트워크 제한으로 검증하지 못했습니다. 브라우저와 CDN 연결 상태, 모델 출력 포맷, 실제 현장 사진 분할 정확도의 추가 시험이 필요합니다. 사진은 사용자 브라우저에서 처리하며 자동 인식 시 모델 라이브러리와 가중치는 외부 CDN/모델 호스트에서 다운로드됩니다. Color101 원본 HEX의 대부분은 이미지 추정값입니다. 실제 제품 색상, 마루의 내수성, 욕실 타일의 미끄럼 저항, 카펫 방염·내구성 및 시공 적합성은 별도 확인해야 합니다. UI 조화 평가는 내부 휴리스틱이며 완성도 승인이나 실사 렌더가 아닙니다.

## 구조
단일 독립 HTML 시제품: `playgrounds/material101/index.html`. 기존 저장소 루트 홈페이지 및 다른 놀이터는 변경하지 않았습니다. 정적 HTML은 직접 열어 수동 편집할 수 있습니다. AI 실행에는 외부 모델·라이브러리 연결이 필요합니다.
